2 Product description
2.1 Product description
KUKA.AMR Studio provides the required functions to commission, config-
ure, and maintain the KMPs.
Features
Features provided by KUKA.AMR Studio include:
• Open box check: KUKA.AMR Studio provides interfaces for KMP hard-
ware condition check to ensure the hardware’s integrity.
• KMP commissioning: KUKA.AMR Studio provides interfaces for KMP
commissioning, including WIFI and 5G network setup.
• Configuration: KUKA.AMR Studio provides interfaces for KMP configu-
ration, including:
‒ Setting speed limits
‒ Sleep strategy
‒ Speaker volume limitation
‒ Sensor calibration
‒ LiDAR configuration
‒ Upper/lower cameras
‒ 3D cameras
‒ Jogging
• Mapping and map extension (LiDAR SLAM, Reflectors and QR code)
• Localization of KMPs in a SLAM map
• Fine localization model management
‒ Model creation (Racks, brackets, reflectors)
‒ Model testing/validation
• Deployment and upgrade of KUKA.AMR OS
• Troubleshooting and diagnosis
Compatibility
KUKA.AMR Studio 2.x is compatible with the following:
• KUKA.AMR OS 2.0 or later
• KUKA.AMR Fleet 1.20 or later
NOTICE
For KUKA.AMR OS 2.0 or later, it is recommended to use the latest
version of KUKA.AMR Studio.

3 Installation
3.1 System requirements
Hardware
• Memory: 8 GB or more
• Storage: 4 GB or more
• Wired Ethernet connection
• Wireless Ethernet connection
Software
• PC with Intel Core i7 or Intel Core i9, or equivalent
• Memory:
‒ 10 platforms or fewer: 16 GB RAM
‒ 11 … 50 platforms: 32 GB RAM
‒ 51 platforms or more: 64 GB RAM
• 200 GB free hard disk space
• Network: no constraints
3.2 Installing KUKA.AMR Studio
KUKA.AMR Studio is a portable software package. It is delivered as a zip
file. No installation wizard or script is required. Simply unzip the file into
the desired folder. This allows for installing multiple versions of
KUKA.AMR Studio on the same PC.
The full path of the installation folder cannot contain any space.
3.3 Running KUKA.AMR Studio
To run KUKA.AMR Studio, browse to the installation folder and double-
click the executable file K-Studio2.x.exe.
User Data Location
User-generated data, such as object models, downloaded maps from the
AMR, are saved in the user-selected folder.
Updating
Since KUKA.AMR Studio is a portable software package, there is no up-
dating process. Simply install the new version as described in
(>>> 3.2 "Installing KUKA.AMR Studio" Page 11 ).
Uninstallation
To uninstall KUKA.AMR Studio, simply delete the installation folder.

5 Configuration
5.1 Establishing a wired connection
For the initial network configuration, the user must establish a wired con-
nection to the AMR. The latter’s static wired IP address is 101.101.2.15.
This enables a wired link to the PC with KUKA.AMR Studio. Refer to the
KMP’s documentation to locate the Ethernet port on the AMR.
Procedure
1. Connect the PC to the AMR using an Ethernet cable.
2. Set up the Ethernet connection on PC.
• Go to the computer’s “Network & Internet” settings.
• Click the Change adapter options  button.
• Right-click the Ethernet button and select Properties.
• Double-click Internet Protocol Version 4 (TCP/IPv4) .
Fig. 5-1: Setting up the Ethernet connection on PC
• Manually configure the IP address as 101.101.2.16 and the subnet
mask as 255.255.255.0, and click OK.
