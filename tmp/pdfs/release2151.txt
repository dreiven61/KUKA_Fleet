Breaking Changes   
 AMR Fleet 
 Security Update: Disable debug ports/pgadmin4 in Fleet 
 disable swagger ports, like 7888, 6688, 8866, 8081, 8082. Only way to enable is editing docker-
compose.yml 
 disable database port 5438. Only way to enable is editing docker-compose.yml 
 disable pgadmin4 in default. You can start it separ ately with command: `docker compose --profile 
pgadmin4 up -d pgadmin4` 
 use "General interface of KUKA.AMR Fleet" with postman instead of using swagger page or 
uncomment the ports you need in docker-compose.yml

 AMR Fleet 
 KMR iico Support 
 Support Conditional Robot Unlock 
 Support auto-retry for KMR iisy

scenarios 
 New `batteryVoltage` field to the Query Robot API `robotQuery` 
 New Opportunity Charging API

Notes 
 The swagger page cannot access in default, because the debug/swagger port is disabled. 
 Default admin password is changed to Admin@001. Other password of existed users is changed to 
Default@001. Please change it.   
 Standard API should be used with token generated by user. It is recommended to create a new user for api 
and avoid using admin. 
 Multiple clients or browsers login with same account is forbidded. Other clients will be logout automatically. It 
is recommended to devide users and save the graph/configuration on time to avoid data loss by logout 
automatically. 
 Please follow the manual to do backup and restore during upgrading KUKA.AMR Fleet 
 Please click „Clear cache“ button in login page after upgrading. If an error „Failed to convert of type...“ occurs 
in monitor, please go back to login page and click „Clear cache“ button. 
 If your previous version is 2.11+, this note can be skipped. Since the area management will not retain the area 
configuration in previous version after the upgrade, it is necessary to backup the area-related information in 
advance before upgrading to this version. After the upgrade, re-add it in the area management. The related 
data of the workflow containing the area also needs to be updated. 
 KUKA.AMR Fleet PDA apk is in pda/KUKA.AMR_PDA.apk in KUKA.AMR_Fleet_[version].tgz
