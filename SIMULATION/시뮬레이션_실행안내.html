가상 AMR 3대 자동 운반

현재 Fleet Monitor에 가상 로봇과 트레이를 추가하고, 각 구간에서 왕복 운반합니다.

AMR 9010189 ↔ 97시작 68 · SIM_CARGO_001
AMR 9010284 ↔ 86시작 69 · SIM_CARGO_002
AMR 9010394 ↔ 96시작 67 · SIM_CARGO_003

실행 순서

  1. Fleet에서 lay01을 Enable하고 로그인 상태를 유지합니다. SIM_TRAY_001 모델이 있어야 합니다.
  2. 아래 실행 코드 복사를 누르고, Fleet 탭에서 F12 → Console에 붙여넣어 Enter를 누릅니다.
  3. Fleet 화면 오른쪽 아래 제어창에서 ① 3대·트레이 준비 → ② 왕복 시작을 누릅니다. 움직임은 Fleet Monitor에서 확인합니다.
Fleet 열기
같은 지도에 실물 또는 가상 여부가 확인되지 않은 로봇이 있으면 실행을 차단합니다. 반복 정지는 다음 작업 전송을 중단하며, 이미 보낸 작업은 계속됩니다. 탭을 닫으면 반복 제어도 중단됩니다.

다시 실행할 때

동일한 Fleet 탭·브라우저에서 실행 코드를 다시 붙여넣으면 제어창이 표시됩니다. 새로고침했다면 ① 준비로 기존 가상 AMR을 확인한 후 시작하세요. 이전 작업이 미확정이면 기록된 작업 번호부터 확인합니다.
